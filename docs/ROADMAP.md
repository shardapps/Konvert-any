# Roadmap

Priorities may change with real usage. This is a plan, not a delivery-date promise.

| Phase | Focus | State |
| --- | --- | --- |
| Foundation | Native picker, core conversions, optional engines, settings, safe output, public CI and policies | Implemented in 0.1 alpha |
| Reliability | More malformed-file tests, large-image budget measurements, input signature validation, engine progress reporting | Planned |
| Windows polish | Compact cursor-positioned popup, modern packaged Explorer command, high contrast, accessibility review, per-monitor behavior | Planned |
| Format expansion | PDF text/OCR, WebP/HEIC/SVG, archives, configurable media presets; licensed modular providers | Planned |
| Workflow | Batches with bounded queue, per-file destination selection, provider management | Planned |
| Distribution | Physical ARM64 tests, signed public previews, Store identity, certification and submission | Planned |

Follow issues and PRs for the current work. Request a format with input/output examples, fidelity expectations and acceptable optional dependencies. Popularity work should grow from useful software, real screenshots, clear documentation and honest sharing; no fake engagement or keyword stuffing.
