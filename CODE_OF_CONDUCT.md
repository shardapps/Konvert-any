# Community code of conduct

Be respectful, focus criticism on work, explain concerns clearly, and give people room to learn. We welcome different backgrounds and experience levels.

Harassment, discrimination, threats, doxxing, sexualized attention, impersonation, spam and publishing private information are unacceptable in issues, PRs, discussions and project spaces.

Maintainers may remove disruptive content, restrict participation or ban contributors. Use proportionate responses: clarification or warning for minor issues, temporary limits for repeated disruption, removal for serious abuse. Maintainers follow the same expectations.

Report misconduct through [GitHub's private abuse reporting](https://docs.github.com/en/site-policy/acceptable-use-policies/reporting-abuse-or-spam) or contact a maintainer through their GitHub profile. Do not post private details in public issues. If a maintainer is involved, use GitHub reporting. Handle reports discreetly, sharing only what investigation and safety require.
